# Convite de aniversário

```
convite/
├── html/index.html      # estrutura da página (abra este arquivo)
├── css/
│   ├── variables.css    # paleta e fontes
│   ├── base.css         # reset e tipografia
│   └── components.css   # hero, selo da foto, botões, formulário
├── js/
│   ├── config.js        # ✏️ edite aqui: nome, data, local, playlist, WhatsApp
│   ├── main.js          # preenche a página com a config
│   ├── countdown.js     # contagem regressiva
│   ├── reveal.js        # efeitos de rolagem
│   └── rsvp.js          # confirmação de presença + confete
└── assets/images/foto.jpg   # coloque sua foto aqui
```

Abra a pasta `convite` inteira (mantenha a estrutura) e dê dois cliques em `index.html` (ele redireciona para `html/index.html`). Não mova arquivos soltos: os caminhos são relativos.
Para publicar, envie a pasta inteira (Netlify, Vercel, GitHub Pages).
